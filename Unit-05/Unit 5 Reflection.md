# Unit 5 Reflection
Unit 5 introduced me to CSS (Cascading Style Sheets) as the essential tool for enhancing website design and presentation. I learned how to manipulate visual properties like font size, font family, and background colors while gaining proficiency in using CSS to precisely size and style images. Additionally, I explored the differences between inline, internal, and external CSS, which taught me how to choose the most efficient method for adding style sheets to a client's web page.
